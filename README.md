# One-Line Roast: The Gadget You Use Every Day

Entry for the [make.fun competition "One-Line Roast: The Gadget You Use Every Day"](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610).

`main.py` drafts ten fresh one-line roasts of gadgets and apps used every
day, grades each on originality, funniness, daily-gadget theme, the
200-character limit, and natural English, and writes the winner to
`/output/entry.txt`:

> My password manager forgot my password — the one thing hired to remember everything now remembers nothing.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/roast-out python3 main.py
cat /tmp/roast-out/entry.txt
```

Python 3, standard library only, deterministic — no network, no randomness, no clock.
